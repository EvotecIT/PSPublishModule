# PSSharedGoods local SMB native boundary

Prepare.ps1 combines two exact pinned external sources without changing their function bodies and extracts the authored C# declaration for bootstrap. The earlier Observe.ps1 loads that declaration directly, then enumerates only the local machine through a null/empty native server argument. SkipDiskSpace is always enabled; no UNC path is opened and no remote server or account is changed. Its direct helper qualification does not exercise normal public dispatch; the public command's mandatory ComputerName rejects an empty array.

ObservePublic.ps1 closes that local public-dispatch gap on the same pinned source. Run its preflight case in a fresh child process, then its public case in separate fresh original and generated children for each claimed Windows host. Preflight loads the extracted declaration and requires a successful, complete local NetShareEnum buffer. The public case imports the module with the native type absent, invokes its exact exported Get-ComputerSMBShareList command with the verified local machine name and SkipDiskSpace, and compares initial, repeated, wildcard, exact and missing-name results with an independently enumerated local buffer. The output records counts and match flags, never share names, remarks or paths. The [public-path evidence](../../../m29a-smb-public-local.json) pins both target artifacts and original/generated results.

A separately owned native buffer supplies the baseline and is freed in finally. A complete, successful, nonempty baseline is required before calling the unchanged workload. Five observations compare output shape, native enum identity, repeated enumeration, wildcard/exact filtering and empty results. A separate fresh-child assembly-refusal observation exercises the caller's failure path. Run each original/generated case in fresh PowerShell 7/net10 and Windows PowerShell 5.1/net472 children. Evidence contains counts and digests, never local share names, remarks or paths.

These fixtures qualify local Hybrid delivery, not native C# translation, remote SMB, disk-space calls, partial buffers or complete-module behavior. The public method already emitted before this additional proof; its private helper stays hosted. The authored helper loops over totalentries instead of entriesread and returns on native failure before its buffer-free finally. Microsoft's NetShareEnum contract treats totalentries as a hint and requires freeing buffers even on ERROR_MORE_DATA. These are source-maintenance concerns; the pinned oracle remains unchanged. A preflight observation does not guarantee that local shares cannot change between calls, and this fixture must run on a stable host. Individually advertised compiled regions are not credited as executed.
