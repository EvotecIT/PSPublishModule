# Password native-call boundary qualification

Prepare.ps1 copies the exact SHA-256-pinned external Set-PasswordRemotely function into an isolated module and extracts its native declaration. No function body is changed. Run Observe.ps1 with original/generated modules and the extracted declaration in fresh PowerShell 7/net10 and Windows PowerShell 5.1/net472 children for each case.

The owned-call case replaces module-local Add-Type with a verified function that returns PfcOwnedPasswordCall, a distinct type with no native imports or network behavior. It validates the authored declaration and expected Add-Type options before returning that type. The substitute checks arguments immediately and retains only counts and booleans. Ten observations cover success/failure information and colors, a thrown call, assembly refusal, owned prompt/empty prompt, target alias, repeated calls and binding refusal. No real Win32.NetApi32 type may exist in these children. Owned sample strings are not credentials; caller SecureStrings remain usable and are disposed by the driver.

The real-no-target case keeps actual Microsoft.PowerShell.Utility Add-Type and replaces only Read-Host with a verified empty result. Child-local environment values force the prompt branch. Two unchanged function invocations load/reuse the real declaration, warn about the absent target and cannot enter the Process password-call branch. The declaration-only case separately loads and reflects the actual four-string, Unicode netapi32.dll signature without invoking it. Environment and modules are restored in finally.

This evidence qualifies hosted delivery around a controlled native-call boundary and actual initialization/refusal. It does not qualify a live password change, native return marshaling, automatic domain-controller discovery, directory/network errors, plaintext zeroization or native dependency deployment. The authored Boolean return loses detailed NET_API_STATUS codes; a nonzero substitute returns information rather than an ErrorRecord or structured failure. Assigning plaintext variables to null and calling GC.Collect does not prove erasure, and exceptional-path cleanup is not guaranteed by the source End block. No live API is invoked, no secret is logged, and no native compilation gain is claimed.
