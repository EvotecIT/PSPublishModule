# Get-AppStoreConnectWebhook
## SYNOPSIS
Lists App Store Connect webhooks for an app.

## SYNTAX
### __AllParameterSets
```powershell
Get-AppStoreConnectWebhook -IssuerId <string> -KeyId <string> -AppId <string> [-PrivateKey <string>] [-PrivateKeyPath <string>] [-TokenLifetimeMinutes <int>] [-Limit <int>] [<CommonParameters>]
```

## DESCRIPTION
Lists App Store Connect webhooks for an app.

## EXAMPLES

### EXAMPLE 1
```powershell
Get-AppStoreConnectWebhook -IssuerId 'Value' -KeyId 'Value' -AppId 'Value'
```
